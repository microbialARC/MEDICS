# Data availability

## Data included in this repository

| Path | Contents |
| --- | --- |
| `data/reference/` | SILOSim profile of *S. aureus* NCTC 8325 (GCF_000013425.1): per-site entropy, contig boundaries, mobile genetic element (MGE) intervals, concatenated reference sequence, and gene annotation |
| `results/tables/` | The 78 candidate loci and the aggregate benchmark tables |
| `results/figures/` | Per-candidate locus plots, the cluster–haplotype Sankey diagram, and monthly time-series plots |

These files are sufficient to reproduce the stage 01 locus scan end to end and
to check every value reported in [results.md](results.md) against its source
table.

## Data not included in this repository

**Genome sequence data.** Raw sequencing reads and genome assemblies for the
CHOP NICU *S. aureus* collection are publicly available from NCBI under
BioProjects [PRJNA1218714](https://www.ncbi.nlm.nih.gov/bioproject/PRJNA1218714),
[PRJNA1390285](https://www.ncbi.nlm.nih.gov/bioproject/PRJNA1390285), and
[PRJNA1219099](https://www.ncbi.nlm.nih.gov/bioproject/PRJNA1219099). They are
not redistributed here.

**Restricted-access data.** The
[THRESHER](https://github.com/microbialARC/THRESHER) result links each
isolate to the clinical identifiers of the patient it was collected from. To
protect patient privacy, it is available only under restricted access.
Per-genome MLST assignments are also not distributed, and this repository
contains no isolate-level data derived from the SNP summary. All files under
`results/tables/` contain aggregate data only: counts per sequence type, counts
per month, and collection-level totals. No record identifies an individual
isolate or patient.

Access can be obtained by contacting the principal investigators, Ahmed M.
Moustafa or Paul J. Planet. Access is subject to institutional review board
approval and a data use agreement. Data will be shared with qualified
researchers for legitimate research use. Requests will be answered within 30
days, and approved access will last for a period based on the study's needs.

**Regenerable intermediate outputs.** Large profiler outputs are excluded. These
are per-genome SNP tables, position coverage, and plot frames, about 144 MB in
total. They can be regenerated by re-running stage 00, and no downstream stage
uses them.

## Configuring local data paths

Stages 02–04 locate their inputs through environment variables resolved in
`analysis/config.R`. Set the variables required by the stage you are running:

| Variable | Dataset |
| --- | --- |
| `MEDICS_THRESHER_SNP_SUMMARY` | THRESHER SNP summary (isolate → strain → transmission cluster) |
| `MEDICS_MLST` | Per-genome sequence type and clonal complex assignments |
| `MEDICS_LOCUS_HAPLOTYPES` | `candidate_aln_haplotype.RDS` from stage 02.5 |
| `MEDICS_LOCUS_SELECTION_DIR` | Stage 03 working directory (intermediates and `best_combo_df.RDS`) |
| `MEDICS_GENOME_ASSEMBLY_DIR` | Directory of assemblies that passed quality control |
| `MEDICS_GENOME_ASSEMBLY_DF` | Table mapping genome names to assembly paths |

If a required variable is not set, the script stops immediately and names the
missing variable, rather than failing partway through.

Two optional variables control runtime behavior rather than data inputs:

| Variable | Effect |
| --- | --- |
| `MEDICS_ROOT` | Repository root, for running scripts from outside the repository |
| `MEDICS_SANKEY_LOCI` | Locus or locus combination to plot in the Sankey diagram (e.g., `cand_13`) |
